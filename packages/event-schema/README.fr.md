# @analyticstrend/event-schema

Le contrat d’échange entre les SDK d’AnalyticsTrend et son collecteur : les types d’événements,
les limites et la validation que les deux côtés partagent.

Volontairement sans aucune dépendance, car il est livré dans les extensions de navigateur des
clients, où chaque dépendance transitive est un risque.

Vous n’avez normalement pas à l’installer vous-même : il arrive avec
[`@analyticstrend/extension`](https://www.npmjs.com/package/@analyticstrend/extension) ou
[`@analyticstrend/web`](https://www.npmjs.com/package/@analyticstrend/web).

Documentation complète : <https://analyticstrend.com/docs/fr/>
