# @analyticstrend/event-schema

El contrato de comunicación entre los SDK de AnalyticsTrend y su recolector: los tipos de evento,
los límites y la validación que comparten ambos lados.

Sin dependencias a propósito, porque viaja dentro de las extensiones de navegador de los clientes,
donde cada dependencia transitiva es un riesgo.

Normalmente no lo instalas directamente: llega con
[`@analyticstrend/extension`](https://www.npmjs.com/package/@analyticstrend/extension) o
[`@analyticstrend/web`](https://www.npmjs.com/package/@analyticstrend/web).

Documentación completa: <https://analyticstrend.com/docs/es/>
