# @analyticstrend/event-schema

O contrato de comunicação entre os SDKs do AnalyticsTrend e o coletor dele: os tipos de evento, os
limites e a validação que os dois lados compartilham.

Sem nenhuma dependência, de propósito, porque ele vai dentro das extensões de navegador dos
clientes, onde cada dependência transitiva é um risco.

Normalmente você não instala este pacote diretamente: ele vem com
[`@analyticstrend/extension`](https://www.npmjs.com/package/@analyticstrend/extension) ou
[`@analyticstrend/web`](https://www.npmjs.com/package/@analyticstrend/web).

Documentação completa: <https://analyticstrend.com/docs/pt/>
