# AnalyticsTrend with Plasmo

A [Plasmo](https://www.plasmo.com) extension instrumented with the AnalyticsTrend extension SDK.
The manifest settings, including Firefox's data-collection block, live under `manifest` in
`package.json`.

```bash
PLASMO_PUBLIC_ANALYTICSTREND_WRITE_KEY=wk_your_key pnpm --filter example-plasmo build
```

Guide: <https://analyticstrend.com/docs/guide/install-plasmo>
